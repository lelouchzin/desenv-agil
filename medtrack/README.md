# MedTrack 💊

Sistema web para controle e acompanhamento de medicamentos, desenvolvido com Angular 17.

## 🚀 Funcionalidades

- **Dashboard** — visão geral do dia com stats, progresso e gráfico semanal de adesão
- **Meus Remédios** — cadastro, ativação/desativação e exclusão de medicamentos
- **Hoje** — lista de doses do dia com ações de tomar/pular e indicador de atraso
- **Histórico** — registro completo de doses com filtro por data e status

## 🛠️ Tecnologias

- Angular 17 (standalone components)
- TypeScript
- SCSS
- RxJS / BehaviorSubject

## ▶️ Como rodar

```bash
npm install
npx ng serve
```

Acesse em: http://localhost:4200
