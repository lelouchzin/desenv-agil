# MedTrack

Aplicação web para controle de horários e lembretes de medicamentos.

## Tecnologias

- Angular 17 (Standalone Components)
- TypeScript
- SCSS
- RxJS / BehaviorSubject

## Como rodar

```bash
npm install
ng serve
```

Acesse http://localhost:4200

## Funcionalidades

- Dashboard com progresso diário
- Cadastro e edição de remédios
- Tela de doses do dia com ações "Tomei" / "Pular"
- Histórico de doses com filtros
