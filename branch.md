# Branch, Integração Contínua e Pull Request

**O que é Integração Contínua?**
É a prática de enviar código ao repositório com frequência, onde testes automáticos validam cada alteração para garantir que nada seja quebrado.

**Qual é o papel das branches nesse processo?**
As branches permitem que cada desenvolvedor trabalhe em sua tarefa de forma isolada, sem interferir no código dos colegas, mantendo o projeto estável.

**Por que o Pull Request é importante?**
O Pull Request permite que a equipe revise e aprove as mudanças antes de integrá-las ao projeto, garantindo qualidade e evitando erros no código principal.
