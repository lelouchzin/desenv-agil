# Requisitos Não Funcionais

A tabela a seguir contém os Requisitos Não Funcionais (RNF) do sistema MedTrack.

| ID    | Requisito                                                                 | Categoria/Tipo            | Prioridade | Requisitos Relacionados |
|-------|--------------------------------------------------------------------------|---------------------------|-----------|------------------------|
| RNF01 | O sistema deve ser responsivo e funcionar em dispositivos móveis.        | Usabilidade               | Alta      | -                      |
| RNF02 | O sistema deve enviar notificações em tempo adequado.                    | Desempenho                | Alta      | RF06, RF07             |
| RNF03 | O sistema deve garantir armazenamento seguro dos dados do usuário.       | Segurança                 | Alta      | RF01                   |
| RNF04 | O tempo de carregamento das telas deve ser inferior a 3 segundos.        | Desempenho                | Média     | -                      |
| RNF05 | O sistema deve possuir interface intuitiva e de fácil uso.               | Usabilidade               | Alta      | -                      |
| RNF06 | O sistema deve estar disponível 24/7.                                    | Confiabilidade            | Média     | -                      |
| RNF07 | O sistema deve ser desenvolvido utilizando tecnologias web modernas.     | Implementação             | Média     | -                      |
| RNF08 | O sistema deve permitir fácil manutenção e escalabilidade.               | Manutenibilidade          | Média     | -                      |
| RNF09 | O sistema deve proteger dados sensíveis conforme boas práticas (LGPD).   | Segurança                 | Alta      | RF01                   |
